## 🧪 Projects & Labs
 
### 🌐 Cisco Enterprise Network Design & Implementation
*Cisco Packet Tracer · CCNA · VLANs · OSPF · RIPv2 · DHCP · SSH · Port Security · Hierarchical Design*
 
Three progressively complex enterprise networks built from scratch in Cisco Packet Tracer:
 
- **SOHO Network** single router/switch, 3 VLANs, inter-VLAN routing, DHCP, wireless
- **Hotel Management Network** 3 floors, 3 routers over serial WAN links, OSPF, SSH on all routers, layer 2 port security
- **Albion University Campus Network** dual-campus topology, 10 VLANs, Cisco 3650 multilayer switches at the distribution layer, RIPv2 across 3 routers, static routing to an external cloud server
Each project starts from a real business scenario requirements analysis, manual subnetting, full device configuration, and end-to-end verification.
 
> [GitHub Repo](https://github.com/Summer-source42/Enterprise-Network-Project)

### 🔧 Azure Honeypot & Attack Map
*Microsoft Azure · Microsoft Sentinel · Log Analytics · KQL*
 
Deployed a cloud honeypot on Azure and used Microsoft Sentinel to ingest and analyze real-world brute-force login attempts. Tracked 17,000+ login attempts from across the globe, built custom KQL queries, and visualized attack origins using geo-location enriched dashboards.
 
Working with real attack telemetry not synthetic lab data made this project much more valuable than a standard tutorial walkthrough.
 
> [GitHub Repo](https://github.com/Summer-source42/azure-honeypot-attackmap)

### 🏢 Active Directory Home Lab
*Windows Server · Active Directory · Group Policy · Splunk · VirtualBox · PowerShell*
 
Built a multi-VM lab simulating an enterprise Active Directory environment. Set up domain services, DHCP, NAT, and DNS on Windows Server, promoted a domain controller, joined client machines to the domain, and deployed Group Policy Objects. Automated the creation of 1,000+ users via PowerShell. Integrated Splunk for centralized log collection and monitoring.
 
> [GitHub Repo](https://github.com/Summer-source42/active-directory-lab)

### 🛡️ File Integrity Monitor
*PowerShell · SHA-512 · Windows*
 
Built a PowerShell-based file integrity monitoring tool that baselines file hashes using SHA-512 and compares them against live values in real time. Detects unauthorized file creations, modifications, and deletions with console alerts a practical introduction to host-based detection.
 
> [GitHub Repo](https://github.com/Summer-source42/file-integrity-monitor)
